PII Redactor

Finds emails, payment cards, IBANs, API keys, national IDs, IP addresses and more — then masks them, in whichever style you need.

🔒 Nothing is uploaded. Ever. All detection and redaction happens in this page, in your browser. There is no server and no network request — you can disconnect your internet and it still works. A redaction tool that sends your document somewhere to redact it would be an oxymoron.
